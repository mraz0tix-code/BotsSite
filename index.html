About

Two Telegram bots in Python. One is a portfolio you can chat with. The other watches your server and reports every login.

Bots

Portfolio Bot

An interactive portfolio. Inline menus show the projects, the Arch Linux setup and the websites. Visitors can write to the author through the bot, and the author replies from the same chat.

Python · aiogram · SQLite

Project code: 270 lines

Login Alert Bot

Follows the SSH log and sends a Telegram alert for each login, failed attempt, sudo or su failure. Each alert has the country, ISP, proxy and VPN flags, reverse DNS and a map pin.

Python · requests · journalctl

Project code: 447 lines

Any text a visitor sends to the chat is forwarded to the author. The author answers by replying to the forwarded message.

Alerts

Event Alert title
Accepted login SUCCESSFUL LOGIN
Failed password or key LOGIN ATTEMPT REJECTED
Too many authentication attempts REJECTED: MAX AUTH ATTEMPTS EXCEEDED
Connection closed before login CONNECTION DROPPED BEFORE AUTH
No banner, failed negotiation, reset connection SUSPICIOUS CONNECTION / SCAN
Failed sudo SUDO AUTHENTICATION FAILED
Failed su SU AUTHENTICATION FAILED
5 or more failures from one IP in 10 minutes BRUTE-FORCE ATTACK DETECTED
Login after 3 or more failures from the same IP SUCCESSFUL LOGIN AFTER MANY FAILURES

To avoid floods, failures are reported at the 1st, 5th, 10th, 25th, 50th, 100th, 250th and 500th attempt per IP, then every 500.

Login Alert Bot settings

Variable Default Meaning
LOG_SOURCE journal journal or file
LOG_FILE /var/log/auth.log Log path when LOG_SOURCE is file. Use /var/log/secure on RHEL and CentOS.
IGNORE_IPS empty IP addresses to skip, separated by commas
BRUTE_THRESHOLD 5 Failures in the window that count as brute force
BRUTE_WINDOW 600 Window length in seconds
SEND_LOCATION_PIN 1 Send a map pin for logins and brute force
NOTIFY_PRIVATE 1 Alert on sources from the local network and loopback

Run

$ pip install aiogram requests
$ python bot.py
$ python3 ssh_bot.py --test
$ python3 ssh_bot.py

Needs Python 3. Portfolio Bot needs aiogram 3 and BOT_TOKEN in the environment or in a .env file. Login Alert Bot needs requests, a bot token and chat ID set near the top of the script, and root or the adm / systemd-journal group to read the logs. The --test flag prints sample alerts and sends nothing.

Keep tokens out of the code and out of git. Add .env to .gitignore.
